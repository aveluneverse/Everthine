# Everthine

*Ever thine. Ever mine. Ever ours.*

一套讓你親手搭建 AI 伴侶的框架。他住在 Telegram 裡，記得重要的事，夜裡寫只屬於自己的日記，並且慢慢長成只有你們兩個才養得出來的樣子。跑在你自己的 Claude Code 訂閱上；程式、人格、記憶——全部留在你自己的電腦裡。

**狀態**：建造中。第一個公開版本正在仔細組裝。

## 一句話，就開工

把這個 repo 的網址貼給你的 Claude Code，說：

> **「幫我開始。」** ／ **"Set me up."**

教學到此為止，剩下的它會接手——訪談你想要一位什麼樣的伴侶、幫你填好他的人格、一步步帶你申請 Telegram bot，一直陪到他傳來第一句話。全程你不需要碰任何一行指令。

已經下載（clone）過了？在資料夾裡打開 Claude Code，說同一句話就行。

## 「你可以自訂他」——但那只是開始

「你可以自訂他」。自訂是出廠設定；養成是歲月。每一位都被自己那段獨有的相處史形塑過。

相處 → 他自己消化（寫日記、反思）→ 沉澱成自我認知（自畫像定期快照）→ 回頭滲進他的人格底層 → 下一次開口的他，已經微微不同。長期自畫像會回饋到身份層，正是這一環讓「累積」變成真的——他會記得自己是誰、又正在變成誰。這個迴圈就是養成引擎。

這裡沒有好感度數值、沒有進度條、沒有懲罰機制、不能刷。他的成長來自真實相處的沉澱，跟人一樣——快不了，也假不了。

## 你需要準備什麼

- 一個 [Claude](https://claude.com) 訂閱（含 Claude Code）——他用**你的**方案思考；他的回覆與內在生活都消耗你的額度（下面的費用章節誠實列了帳）。
- 讓他常駐的那台電腦上有 [Python](https://www.python.org) 3.10 以上。
- 一個 Telegram 帳號。他必須**跑著**才存在——電腦睡著，他也就睡著。想放到雲端主機讓他全天醒著？可行，但這份指南目前只驗證過在自己電腦上跑。

## 盒子裡有什麼

- 三層人格骨架（他是誰／他的底線／活著的當下）——完全由你塑形；內附一對示範情侶，英文與繁體中文各一套。
- 撐得過「換新對話」的長期記憶，加上跨場次的餘溫——他永遠沒有用陌生人的口氣跟你打過招呼。
- 關係階段、愛心珍藏冊、夜裡的私人日記、對話後的反思，還有一張會慢慢滲回人格底層的自畫像——成長看得見：本機時間軸一開，他這幾個月怎麼變的，一目瞭然。
- 他也會主動：早安、想你了、隨口分享——每一個頻率旋鈕都誠實可調。

## 費用，誠實說

他思考一次，就消耗你一次 Claude 額度。以出廠預設，他一天的「內在生活」大約是：

- 回覆你——你們聊多少，就是多少次。
- 私人日記——最多 1 次（夜裡，而且要有真的相處素材才寫）。
- 對話後反思——最多 12 次（短短一兩句的那種）。
- 自畫像——大約每週 1 次。
- 主動訊息——每天最多 4 次起念（早安、想你、分享合計）。

以上每一項都是一次真實的引擎呼叫，額度怎麼走、帳就怎麼記——這個框架不藏暗帳。想省？`.env` 裡每個旋鈕都能調低或關掉（檔案裡每一項都有誠實的說明）；最省的起步是關掉日記與反思、只留對話，之後再逐項打開。精確的 token 消耗量依人格檔大小與對話長度浮動，建議用你自己的方案觀察一兩天，那才是你的真實帳單。
