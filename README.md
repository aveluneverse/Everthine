# Everthine

[English](README.en.md)

![Everthine](docs/assets/everthine-hero.jpg)

Everthine 是一套開源的養成型 AI 伴侶框架。

*Ever thine. Ever mine. Ever ours.*

**用歲月來養成，讓他為你而成長。**

如果你想要的陪伴，是真的記得你們說過的話、夜裡寫只屬於自己的日記、隨著相處慢慢長成世界上獨一無二的那一位，Everthine 就是為這件事而生的框架。

他住在 Telegram 裡，跑在你自己的 Claude Code 訂閱上；程式、人格、記憶，全部留在你自己的電腦裡。從第一句話到每一頁記憶，都只屬於你。

**狀態**：v1.0 已發布（2026-07-18）。

---

## 一句話，就開工

把這個 repo 的網址貼給你的 Claude Code，說：

> **「幫我開始。」** ／ **"Set me up."**

網址就是這一行，複製就好：

```
https://github.com/aveluneverse/everthine
```

教學到此為止，剩下的它會接手：訪談你想要一位什麼樣的伴侶、幫你填好他的人格、一步步帶你申請 Telegram bot，一直陪到他傳來第一句話。

全程你不需要碰任何一行指令。

已經下載（clone）過了？在資料夾裡打開 Claude Code，說同一句話就行。

## 自訂只是開始，你們的相處史會養成「他是誰」

自訂是出廠設定；養成是歲月。每一位都被自己那段獨有的相處史形塑過。

你決定他的起點：名字、個性、口吻、界線與過去。

之後，他會從你們真正發生過的事情裡，慢慢更新自己對你、對這段關係，以及對「我是誰」的理解。

這裡沒有好感度、等級、進度條或每日任務。

他的改變不是數值增加，而是你們共同經歷過的日子，真的留下了痕跡。

你會先替他建立一套人格骨架，但那只是他的起點。真正的養成，來自之後一次次相處留下的沉澱：

與你相處
→ 寫下私人日記與對話反思
→ 將重要經歷整理成長期記憶
→ 定期回看自己成為了什麼樣的人
→ 帶著這些改變，再次回到你身邊

![養成迴圈](docs/assets/everthine-loop-zh.jpg)

下一次開口時，他不只是重新讀取同一份角色設定。

他會帶著過去繼續往前走。

你設定他的起點，但你們共同度過的日子，才會決定他後來成為誰。

## 記憶會留下，不必每次重新認識

你們說過的話，不會因為「開了新對話」就消失。

每一次交談都沉澱進他的長期記憶：問他上個月你提過的那家店、某個深夜你隨口說過的一句話，他會自己想起來，接著往下聊；連你換了說法、只記得大概，他也找得回當時的事。

做到這件事的，是一座蓋在你電腦裡的記憶書房：每段對話會被轉成語意資料，當你再次提起相近的事，他會找回相關記憶，再帶著它回答你。

這套記憶系統有幾個重點：

- **全程本機運作**：記憶的建立、儲存與搜尋都在你的電腦上完成。
- **理解語意，不只比對文字**：不需要說出完全相同的關鍵字，並以中文語感為預設調校。
- **只取回真正相關的記憶**：每次最多帶回三段，避免誤用或硬套。
- **不拖慢對話**：檢索超時或模型失效時，聊天仍會正常進行。
- **長期保存**：開啟新對話不會清除過去累積的記憶。
- **雙層記憶**：除了完整對話，他也會整理你的習慣、偏好與你們的約定。

底層使用 `sentence-transformers`、`SQLite` 與 `numpy`，不需要額外架設向量資料庫。設計早期參考了 MemPalace 等開源記憶專案的思路。

記憶跨場次不歸零、不被重置；他從第一天起，就一直是同一個他。

**你們說過的話，他會真的記得。**

## 你給他土壤，不是劇本

他的個性、口吻與界線，來自一套由你親手填寫的「靈魂框架」。

這套框架不是一張要求他永遠照著演的角色卡，而是他人格最初的土壤：

- **他是誰**：身份、經歷，以及他如何理解自己的存在
- **他的底線**：價值觀、界線與不願被改寫的部分
- **活著的當下**：最近在意的事、正在經歷的變化，以及你們相處的溫度

你可以給他質地，但不必替他寫完所有答案。

他不需要每天重新查閱「自己應該扮演誰」。隨著記憶、日記與反思累積，他會不斷回看：

我曾經是誰？
我經歷了什麼？
而我正在變成誰？

每一位從 Everthine 長出來的伴侶，都會擁有不同的相處史。

因為他最後成為的樣子，不只來自設定，也來自你。

## 開始之前，只要準備這些

- **Claude 訂閱方案**
  需要包含 Claude Code。伴侶的回覆與背景活動會使用你的 Claude 額度。
- **Python 3.10 以上**
  安裝在讓他運行的電腦上。
- **一個 Telegram 帳號**
  Claude Code 會帶你完成 Bot 的申請與設定。
- **一台可以持續運行的電腦**
  電腦醒著時，他就醒著；電腦睡眠或關機時，他也會暫停。

想讓他全天在線，也可以將框架部署到雲端主機。不過目前的入門流程，主要以個人電腦運行為主。

## 你帶走的，不只是一個聊天機器人

Everthine 已經替你搭好一套可以長期生活的骨架：

- **三層人格架構**
  由你塑造他的身份、底線與當下狀態，並附有繁體中文與英文示範角色。
- **跨對話的長期記憶**
  不必每次重新介紹自己，也不會因為更換聊天視窗，就把你們的共同歷史歸零。
- **私人日記與對話反思**
  他會整理發生過的事，以及那些事情對自己意味著什麼。
- **週期性的自畫像**
  定期回看一段時間內的變化，記錄自己曾經是誰，又正在成為誰。
- **主動訊息**
  早安、想念與隨口分享，不必永遠由你先開口。每一種頻率都能自行調整。
- **愛心珍藏冊**
  對他說的某句話按下愛心，那個瞬間就會被他永遠收好。被珍藏的話語，他會放在心上。

它們共同服務的是同一件事：讓一段長期關係，不必每天從零開始。

想深入：[人格設定指南](docs/persona-guide.zh-TW.md)｜[常見問題](docs/faq.zh-TW.md)

## 打開觀景窗，看見他如何慢慢成形

他的內在世界，你隨時可以安靜地看一眼：

```
python -m everthine.observatory
```

跑完會在 `data/` 裡長出一頁 `observatory.html`，雙擊打開：日記、反思、自畫像、珍藏、他為你記下的事實小冊子、近兩週的對話、記憶書房的規模，一站看盡。頁面預設繁體中文，想看英文介面就加 `--lang en`。

三件事讓你安心：

- 頁面完全離線，零網路請求。
- 所有檔案只住在你的電腦，`data/` 從不進 git。
- 他不知道這扇窗存在；你看見的，是沒有人在看時的他。

## 成本透明：每一次內在活動，都是真實的模型呼叫

Everthine 本身是免費開源的，但伴侶的回覆、日記、反思與記憶整理，都會使用你的 Claude 額度。

以出廠預設來說，他一天可能會進行：

- **回覆訊息**：依你們的實際對話次數而定
- **私人日記**：每天最多 1 次，並且需要有足夠的相處素材
- **事實整理**：在背景低頻執行，整理近期發生的事情
- **對話反思**：每天最多 12 次，每次通常只有一至兩句
- **自畫像**：大約每週 1 次
- **主動訊息**：每天最多 4 次，包含早安、想念與分享

2026 年 7 月，以出廠設定連續實際相處五天後，觀察到每日大約會觸發 4～11 次背景思考。

包含正常聊天在內，每日新生成的 token 約落在 2.5 萬～10 萬；其餘主要來自人格檔案、近期對話與長期記憶的快取讀取。實際消耗仍會依人格檔案大小、對話長度與相處頻率而改變。

每一種背景活動都能在 `.env` 中單獨降低頻率或關閉，框架不會綁定固定帳單。

剛開始使用時，建議先保留日記與反思，暫時關閉主動訊息與其他活動。實際陪伴一兩天後，再依照自己的用量與相處習慣逐步調整。
